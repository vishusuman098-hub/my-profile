## How to run

1. Open the project folder.
2. Double-click `index.html` or open it in a browser.
3. No Node.js or build command is required.

## GitHub setup

```bash
git init
git add .
git commit -m "Create Vishu Suman portfolio"
git branch -M main
git remote add origin https://github.com/vishusuman098-hub/YOUR-REPOSITORY.git
git push -u origin main
```

Replace `YOUR-REPOSITORY` with the name of your GitHub repository.

## GitHub Pages

Open your repository on GitHub and go to **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
